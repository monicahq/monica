# Ask for help

When something is broken, confusing, or missing, you can write to the people who run your Monica without leaving it. On the hosted version, that is us. On an instance someone runs for you, it is whoever administers it.

Open the menu under your picture and choose **Help and support**. If the entry is not there, nobody administers this instance yet, so there is nobody to write to.

## Send a request

1. Choose what you need help with: a feature you would like, a billing question, emails you are not receiving, something you find confusing, or something you think is broken. The page then gives a few hints for that kind of request.
2. Write a **Subject**: a short summary you will recognise later.
3. Explain what is going on. The more context you give, such as what you did, what you expected and what happened instead, the faster someone can help.
4. Add files if they help, such as a screenshot or an invoice. You can send up to five, of up to 10 MB each, as images, PDF or text.
5. Choose **Send message**.

The next screen shows the request number, such as **MON-482913**. Keep it if you write about the request later. A copy of what you sent arrives in your inbox.

Files you send to support do not count against the storage of your account.

## Format your message

A request, a reply and every message after them can use Markdown, a few simple marks that become formatting once the message is sent. It helps when you describe steps or paste an error, but plain sentences work just as well.

| Write | To get |
| --- | --- |
| `## What happened` | a heading |
| `- The vault` | a bullet |
| `1. Open the vault` | a numbered step |
| `> The reminder never came` | a quote |
| `**before Friday**` | bold text |
| `` `Error 500` `` | a short piece of code |
| `[the page](https://www.example.com)` | a link |

To paste a longer error or a log, put a line of three backticks (` ``` `) above it and another below it. Everything between them is shown exactly as you pasted it.

A web address you type, such as `https://www.example.com`, becomes a link on its own. HTML is shown as the characters you typed, and an image appears as a link to its address rather than as the picture.

## Follow a request

**Your requests** lists everything you have asked, with the latest activity on top. **Open** holds what is still in progress; **Solved** keeps the old answers, so you can find them without searching your inbox.

Each request shows where it stands:

- **Waiting for support**: a person has not answered yet.
- **Reply from support**: someone answered and is waiting for you.
- **Solved**: nothing more is needed.

When someone replies, you also get the reply by email, with a link to the request.

## Reply or close it

Open the request, write in **Your reply**, add files if needed, and choose **Send reply**. It goes back to the support team.

:::note
Replying to the email does not reach anyone. Always answer from the request page.
:::

Once you have what you needed, choose **Mark as solved**. If the problem comes back, write in the same request: it reopens with the same number.

## From the API or an assistant

Everything on this page is also possible through the API and from an assistant connected over MCP, except sending files from an assistant. The API reference describes it under **Support requests**.
