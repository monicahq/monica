Until now, a message to the support team was plain text, so steps and pasted errors ran together and anything that looked like code could disappear. Now you can write lists, bold text, links and code blocks in Markdown, in a request and in every reply, and the thread shows them formatted. What you paste is kept exactly as you typed it.
