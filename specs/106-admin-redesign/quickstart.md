# Quickstart: Admin space redesign

The commands that gate the change are the ones in `CLAUDE.md`, under "When a change is done".

## By hand, at `https://erica.test/admin`, signed in as an administrator

| Check | Expected |
| --- | --- |
| Open each of the seven sections | Band, bar, badge and warning strip on every one; exactly one section marked current |
| Switch to the dark theme | The bar stays dark, the warning strip takes the dark warning colours |
| Width 320 pixels | Full warning sentence, sections scroll sideways, no horizontal page scroll |
| Zoom 200% | Nothing clipped or overlapping |
| Keyboard only, from the top | Every section, "Leave the admin space", theme switch, account menu, "Count again" and "Open moderation" reachable with a visible focus ring |
| Screen reader on the email bar | One sentence with all four counts and the total |
| Change the clock to 12 hour in settings | "Counted at" follows it |
| Print preview | No band, bar or warning strip |
