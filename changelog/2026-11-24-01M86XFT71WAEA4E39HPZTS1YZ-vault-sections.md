Vault settings now has a panel called **What this vault shows**. Switch off People, Things or Knowledge and that section leaves the vault’s sidebar, and People leaves its search too. Nothing is deleted: every record still opens from a link, and the API and connected assistants still reach all of it. The API and the MCP server can change the setting as well.
