title: Ampersands and angle brackets are now saved as you type them
type: fix
area: Contacts
published_at: 2026-11-26T15:22:37Z
---
Until now, an ampersand or an angle bracket typed in a name, a field or a note was saved as an HTML code, and that code showed on screen, in the API and in your export in place of the character. Now what you type is saved and shown as you wrote it. Texts saved before this fix keep the code.
