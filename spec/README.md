# Spec

This folder holds the written specification of Monica (the code name of Monica v3), turned into something the application can be built from.

| File or folder | What it holds |
|---|---|
| `spec.md` | The product specification itself, translated from the original French. It is the source every other file in this folder refers to by section number. |
| `models/` | One file per model, numbered in the order they must be implemented. |

Nothing in this folder is code. It describes what each object is, why it exists, the columns it carries and the rules it must obey. The implementation follows the conventions in `.claude/rules/` and `.claude/skills/`.
