# Components

- Components MUST be stored in the `resources/views/components` folder.
- When a component is part of a concept that is bigger, like buttons, it MUST be stored in a subfolder of the `resources/views/components` folder.
- Before writing one, read [components.md](../../rules/components.md): which existing component to reach for, the three file bar, and the traps in slots and Alpine.
